현재 경제는 과거의 어떤 충격과 닮아 있을까?

파일을 열면 2026년 6월까지의 내장 예시 데이터로 대시보드가 즉시 표시되며, ECOS 인증키를 연결하면 한국은행의 9개 핵심 시계열로 교체하여 외환·물가·실물경제·고용·금융시장·대외건전성의 6개 영역으로 재구성합니다. 금융시장은 회사채–국고채 신용스프레드로 평가하고 KOSPI 추이를 보조지표로 함께 표시하며, 대외건전성은 외환보유액과 경상수지로 계산합니다.

점수 해석

  • 스트레스 점수는 각 지표가 장기 분포에서 차지하는 상대적 위치입니다.
  • 유사도 점수는 현재와 과거 사건의 6개 영역 간 거리로 계산합니다.
  • KOSPI는 시장 흐름을 이해하기 위한 보조지표이며, 기본 종합점수에는 포함하지 않습니다.
  • 점수가 높아도 경제위기 발생 확률이나 투자 판단을 의미하지 않습니다.

데이터 갱신

파일을 처음 열면 2026년 6월까지 생성된 내장 예시 데이터가 즉시 표시됩니다. 우측 상단 ⋮ 메뉴의 ‘ECOS 인증키 연결’에서 키를 입력하면 공식 통계를 조회합니다. HTML 파일을 직접 여는 방식은 브라우저의 교차 출처 보안정책으로 차단될 수 있으므로, 공식 데이터 이용 시 ZIP에 포함된 대시보드_실행.bat을 실행하는 방식을 권장합니다. 공식 통계는 지표별 발표 시차가 달라 최신 공통 기준월이 예시 기준월보다 앞설 수 있습니다.

ECOS Open API 안내

ECOS 데이터 연결

연결 진단을 실행하면 인증키 문제와 브라우저 보안 차단을 구분해 안내합니다.

인증키는 현재 브라우저 탭의 sessionStorage에만 저장되며 HTML 파일에는 기록되지 않습니다. HTML 파일을 직접 열었을 때 브라우저가 ECOS 요청을 차단하면 ZIP에 포함된 대시보드_실행.bat을 사용해 주세요.

통계코드 설정

권장 통계표 코드는 미리 반영되어 있습니다. 항목코드는 ECOS 항목명으로 자동 매칭하며 필요 시 직접 수정할 수 있습니다.
사용영역표시명통계코드항목1항목2항목3항목4주기변환위험방향가중치

통계표 코드는 권장값이 입력되어 있으며, 빈 항목코드는 API 연결 시 항목명과 수록기간을 기준으로 자동 확인합니다. 국고채와 회사채는 원자료로 수집한 뒤 신용스프레드로 계산됩니다. KOSPI는 별도 추이와 전년동월비를 제공하며 종합 유사도 점수에는 기본적으로 반영하지 않습니다.
